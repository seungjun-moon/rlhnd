# RLHND project page

Project page for **RLHND: Video Foundation Models as Physically Grounded Hand Trackers for Robot Learning**.

- Paper: [arXiv 2610.09455](https://arxiv.org/abs/2610.09455) · [Hugging Face Papers](https://huggingface.co/papers/2610.09455)
- Code: coming to this repository.

- `index.html` — the page (static; relative `videos/` paths, Google Fonts is the only external dependency).
- `videos/` — result clips embedded in the page.
- `logo.svg` — site logo.

Deployed at https://seungjun-moon.github.io/rlhnd/ (GitHub Pages, root of `main`).
